# Windows XP Web OS — GitHub Actions APK

1. Create a GitHub repository.
2. Upload this whole project.
3. Open GitHub **Actions**.
4. Run **Build Windows XP Web OS APK**.
5. Download the `Windows-XP-WebOS-debug` artifact.
6. Extract it and install `app-debug.apk`.

The HTML app is `app/src/main/assets/index.html`.
The Android WebView includes JavaScript, DOM storage, hardware acceleration,
media playback and a native Android file picker for multiple file selection.
Do not bundle large MP4/MP3 files inside the APK.
